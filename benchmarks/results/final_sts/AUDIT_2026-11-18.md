# IndicVoice — Phase Zero Audit (2026-11-18)

Read from the code, not from the specification. Every claim below points at the
file and function it was taken from.

## 1. The pipeline that actually runs

```
Browser mic (AudioWorklet, 1024-sample batches, resampled to 16 kHz in JS)
  │  WebSocket /ws/voice  raw PCM16 LE
  ▼
call_server.voice() ──> CallSession.feed()  (re-knitted into 512-sample VAD windows)
  ▼
CallSession._process_frame()
  ├─ _gate(): speaker-bleed gate, -32 dBFS while the agent is talking
  ├─ barge-in: sustained speech ≥ 0.45 s while speaking → cancel LLM + flush audio
  ├─ vad.accept_waveform(frame)          Silero VAD, threshold 0.5,
  │                                       min_speech 0.25 s, min_silence 0.26/0.45 s
  ├─ StreamingSTT.start()/accept()       pre-onset ring buffer (≈0.5 s) as seed
  ▼  VAD endpoint (segment popped, ≥ 0.3 s)
run_in_executor(asr_executor) StreamingSTT.finalize()
  ├─ speculative full-buffer decode started 0.12 s into trailing silence
  ├─ else authoritative full-buffer decode
  ▼
_clean_transcript()  (hallucination filter)
  ▼
VoiceAgent.maybe_switch_language()   script-based, session default wins ties
  ▼
VoiceAgent.start_response() → worker thread "llm-tts"
  ├─ LLMClient.stream_chat()      keep-alive socket, SSE, model fallback on 429/503
  ├─ SentenceSplitter → ensure_script() (romanised Indic → native script)
  ├─ TTSPool.speak_sentences() → TTSEngine.render_sentence()
  │      TextNormalizer → localize_text → per-clause synth → room tone → seam crossfade
  └─ AudioSink.push() → queue → CallSession.sender() → WebSocket binary frames
  ▼
Browser: AudioBufferSourceNode scheduled back-to-back (playAt cursor)
```

Telephony path is the same object graph with 8 kHz mu-law at both edges
(`/ws/telephony` → `ulaw_decode` → `resample` → … → `ulaw_encode` → 20 ms frames).

## 3. Defect register (ranked, this pass)

| # | Defect | Evidence | Status |
|---|---|---|---|
| F1 | A barge-in cancelled playback but the TTS worker was usually mid-clause; that clause reached the sink 100–600 ms later, so the interrupted reply kept talking over the user | `AudioSink.cancel()` reset `_until` only; `synthesize()` passes its cancel callback **only** in the MMS branch, so tiny/Supertonic cannot abort mid-generation | **FIXED** — `AudioSink`/`AudioPlayer` mute between `cancel()` and the next turn’s `resume()`; TTS checks the cancel event again before emitting |
| F2 | One short Latin utterance (“ok”, “hello”) flipped a whole Hindi call to English for the rest of the session | `detect_lang()` maps any Latin script to `en`; `maybe_switch_language()` switched on the first non-matching turn | **FIXED** — Latin evidence must be ≥ 3 words; an Indic script still switches on one word |
| F3 | Endpoint silence stayed at the value of the language the call *started* in, so a Hindi→English switch kept 0.26 s although English needs 0.45 s (earlier V1 measurement: 0.45 s truncated two-sentence English turns) | `CallSession.__init__` set `min_silence` once from the start language | **FIXED** — `_retune_endpoint()` follows the turn language; an explicit `?endpoint=` still wins |
| F4 | Gujarati: one internal pause exceeded the 0.26 s endpoint → **1 turn split**, i.e. the agent would answer half a question, then answer the rest as a second turn | `stage_bench_latest.json` → `vad_turn_splits: 1`, endpoint delay −2 208 ms | **OPEN** — do not retune on synthetic audio; needs real recordings |
| F5 | `AudioSink.is_speaking` is a wall-clock estimate from emit time, not client playback; network jitter skews the echo gate and barge-in window | `AudioSink.push()` sets `_until = monotonic + duration` | **OPEN** (known D20) — needs a client playback ack |
| F6 | hi/mr and bn/as are script-indistinguishable; the session default always wins the tie, so a Marathi caller in a Hindi-default session stays on the Hindi recogniser | `detect_lang()` → `candidates` order | **OPEN** (known D21) — needs a language probe or explicit selection |
| F7 | Tiny/Supertonic TTS cannot abort mid-generation (no cancel callback reaches them) | `TTSEngine.synthesize()` MMS-only `callback` | **MITIGATED** by F1 (output dropped); generation still wastes CPU after a barge-in |

## 4. What was changed in this pass

| File | Change | Why |
|---|---|---|
| `src/call_server.py` | `AudioSink._accepting`, `resume()`, mute in `push()`; `_endpoint_override`; `_retune_endpoint()` | F1, F3 |
| `src/tts_engine.py` | `AudioPlayer._accepting`/`resume()`; cancel checks before `_emit()` in both `speak_sentences` paths | F1 |
| `src/sts_pipeline.py` | `respond()` resumes the sink; `_LATIN_SWITCH_MIN_WORDS = 3` evidence gate | F1, F2 |
| `tests/test_turn_taking.py` | 10 regression tests | pins F1–F3 |
| `benchmarks/run_stage_bench.py` | offline per-stage benchmark (VAD, TTS, ASR, CER, RSS) | Phase 6 instrumentation |

No provider, model, prompt-rule or tuning constant was removed.
